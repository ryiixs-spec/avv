# ☁️ Thank You — Interactive Cloud Letter

Website personal, dreamy, dan interaktif yang diakses melalui QR Code / Web. Dibangun dengan Next.js, React, Tailwind CSS, dan Framer Motion.

## ✨ Fitur Utama
- 💌 **Opening Screen**: Amplop 3D interaktif dengan segel lilin bintang berkilau dan taburan konfeti.
- 🎵 **Music Player**: Memutar lagu **The 1975 — About You** (mulai menit `1:22` dengan loop) dan visualizer audio equalizer.
- ✨ **Intro Transition**: Teks bercahaya *"thank youu for ur sweet word for me."*
- ☁️ **Above the Clouds Scene**:
  - Matahari bercahaya lembut (*Sun Glow*).
  - 3 Layer pegunungan anime bergradasi dengan siluet pohon pinus dan kabut.
  - Awan SVG bergerak melayang dan mengapit sisi kiri-kanan.
  - Kawanan burung terbang dua arah.
  - Partikel bintang berkilau (`✦`, `·`, `✧`).
- 💬 **Interaktif**: Klik awan atau bintang untuk memunculkan pesan motivasi acak dan harapan kecil.
- 📖 **Surat Glassmorphism**: Kartu surat frosted glass modern dengan animasi *staggered scroll-reveal*.
- 🌅 **Sunset Scroll Transition**: Gradien langit berubah secara dinamis saat di-scroll menuju nuansa senja.

## 🚀 Menjalankan Secara Lokal

```bash
# Install dependencies
npm install

# Jalankan server development
npm run dev

# Buka http://localhost:3000
```

## 📦 Deployment ke Vercel

1. Push repository ini ke GitHub.
2. Buka [vercel.com](https://vercel.com) dan impor repository GitHub Anda.
3. Klik **Deploy**.
